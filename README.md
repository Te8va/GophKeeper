Серверная часть для менеджера персональных данных. Реализована базовая аутентификация пользователей: регистрация и вход по логину/паролю с выдачей JWT-токена в куки. Поддерживает безопасное хранение различных типов конфиденциальных данных (логины/пароли, текстовые данные, бинарные данные, банковские карты). Хранилище — PostgreSQL, маршрутизация — chi, миграции — golang-migrate.

Приложение работает на порту 8080. 

Запускается через docker-compose up.
go run .\cmd\gophkeeper\main.go для запуска кода

Флаги командной строки
-a — адрес HTTP-сервера

-b — базовый URL для коротких ссылок

-d — строка подключения к БД

-f — путь к файловому хранилищу

-l — путь к файловому хранилищу аутентификации

-c, -config — путь к конфигурационному файлу (JSON)

Программа имеет следующие энпоинты.

POST /user/register — регистрация пользователя
POST /user/login — вход пользователя
Тело запроса:

{
  "login": "user@example.com",
  "password": "strong_password"
}

При успехе: статус 200, JWT-токен устанавливается в cookie

Создание записи
POST /data

Тело запроса:

{
  "type": "login_password",
  "metadata": "Описание записи",
  "data": "data"
}

Получение всех записей
GET /data

Ответ:

[
  {
    "id": "uuid",
    "type": "login_password",
    "metadata": "Описание",
    "data": "данные в строковом формате"  }
]

Получение записи по ID
GET /data/{id}

Обновление записи
PUT /data/{id}

Тело запроса аналогично созданию записи.

Удаление записи
DELETE /data/{id}
